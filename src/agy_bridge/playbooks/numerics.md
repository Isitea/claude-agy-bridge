# 수치 안정성 (numerics)

확인하라:

- 이산화(격자·시간 간격·기저 크기)의 수렴이 확인되는가. 수렴 검증 계획이 타당한가.
- 수렴 기준이 물리량의 스케일에 맞는가 (절대/상대 허용오차 혼동, 스케일이 다른
  변수들에 단일 기준 적용).
- 강성(stiff) 문제에 부적합한 적분기를 쓰지 않는가. 조건수가 나쁜 연산
  (크기가 비슷한 큰 수의 차, 지수 오버플로/언더플로)이 있는가.
- 반복 해법의 수렴 실패가 조용히 무시되지 않는가. 실패 시 값이 그대로
  하류로 흘러가는 경로가 있는가.
- 부동소수점 함정: 취소 오차, 로그-합-지수(log-sum-exp) 미처리, 허용오차와
  물리적 불확실성의 혼동.
